How it works: This is a Grand Canonical Lattice Gas simulation (equivalent to the Ising model).

Drag the interactive circle in the Phase Diagram to change the Temperature (T) and Chemical Potential (μ).

- High T: Supercritical fluid (chaotic).
- Low T, μ > 0: Liquid (dense, clustering).
- Low T, μ < 0: Gas (sparse).

Info

This simulation uses a Grand Canonical Monte Carlo approach on a 2D lattice. At T < T_c and μ ≈ 0, the system exhibits liquid-gas coexistence. For T > T_c, it enters a supercritical state where phase boundaries vanish.
